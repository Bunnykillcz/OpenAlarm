OpenAlarm is an Arduino Nano alarm with a keypad, sensor input, status LEDs, buzzer & optional external siren. This repository contains the firmware, PCB designs & enclosure files. Licensing is governed by the [NejedNiko Software Licensing Framework](https://github.com/Bunnykillcz/NejedNiko_Software_Licensing_Framework). See [LICENSE](LICENSE) for the terms that apply to OpenAlarm.

## Build documentation

Start with the [bill of materials](docs/BOM.md), then follow the [build manual](docs/Manual-Build.md). The [usage manual](docs/Manual-Usage.md) covers arming, PIN entry & disarming.

| Directory | Contents |
| --- | --- |
| [code/NNOpenAlarm](code/NNOpenAlarm) | Arduino firmware |
| [schematics](schematics) | Board images, schematic & PCB manufacturing archive |
| [dimensions](dimensions) | STL enclosure parts & OBJ model |
| [docs](docs) | Build manual, usage manual, parts list & assembly photos |

You'll need an Arduino Nano, the components in the parts list, a soldering iron, a USB cable & a multimeter.
